## 幻灯备注

Remarkjs 提供不错的演示功能。编写幻灯时，可通过“???”来添加备注，像这样：

```markdown
## 幻灯备注

Remarkjs 提供不错的演示功能。编写幻灯时，可通过“???”来添加备注，像这样：
???
虽然可以添加备注，但最好不要添加大段文字照着念，那样很容易像念课文似的，观众马上就会昏昏欲睡。如果你发现自己写了大段内容，
要想想是否还是没有把精髓提炼出来，毕竟演讲不是给学生上课，细节过多往往会变成讲给自己听。
```

在实际演讲的时候，按 `P` 键切换到演示模式就可以看到备注。当然演示模式是留给自己看的，所以你要先按 `C` 键打开一个新浏览器窗口，将其放置到投影所在的副屏上并按 `F` 键最大化。想要了解全部快捷键，按 `H` 键即可。
