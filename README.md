## 项目简介

**智析课堂** 是一款基于 AI 智能体的智慧课堂教学平台，以对话式 AI 辅助课件生成与即时反馈机制革新交互模式，构建课程与课堂双维度教学分析体系，实现全景式学情洞察。

---

## 解决痛点

传统课堂面临三大核心痛点：

| 痛点 | 表现 |
|------|------|
| **课件制作耗时** | 教案、课件、习题重复编制，挤占教学与个性化辅导时间 |
| **反馈滞后** | 学情评价停留于平均分，难以定位具体知识点掌握情况 |
| **学情模糊** | 教师依赖经验判断，缺乏数据驱动的精准诊断 |

---

## 实现功能

### 对话式 AI 辅助备课

- **课程大纲生成** — AI 根据课程名称、学科、年级自动生成教学大纲
- **教案生成** — 基于大纲生成完整教案，包含教学目标、重难点、教学过程
- **课件生成** — 根据教案自动生成 PPT 课件大纲
- **实验指导书生成** — AI 生成实验目的、原理、器材、步骤
- **题库生成** — 按知识点、难度、认知层次分层出题
- **讨论话题生成** — 生成课堂讨论话题，包含引导问题和评分标准

### 全景式学情洞察

- **课程与课堂双维度分析** — 从宏观课程到微观课堂的多层级学情分析
- **知识点掌握热力图** — ECharts 可视化展示知识点掌握情况
- **学生画像** — 综合课堂参与、作业得分、互动质量生成个体画像
- **异常行为预警** — 自动识别学习异常，及时提醒教师

### 防 AI 空转机制

- **强制完整思维链条** — 打破 AI 导致的流程空转，强制学生经历完整思考过程
- **引导式 AI 交互** — 先思考后求助，避免技术替代思考
- **思维过程追踪** — 学生思维过程得以完整保留与追踪

### 课堂互动与思维链激发

- **课堂签到** — 二维码签到，实时统计出勤
- **话题讨论** — 教师发布话题，学生端实时接收并回答
- **思维链引导** — AI 不直接给出答案，通过追问、提示、反问等方式调动学生完整思维链条
- **学情即时分析** — 根据学生回答质量、思考时长、互动深度，实时生成学情诊断报告
- **防 AI 空转** — 强制学生先独立思考再求助，AI 仅作为引导者而非答案提供者，确保技术不替代思考
- **实时流式输出** — SSE 推送 AI 生成内容，无需等待完整响应

### 智能体职责

| 智能体 | 职责 | 输出 |
|--------|------|------|
| **CourseOutlineAgent** | 根据课程信息生成教学大纲 | 结构化大纲文本 |
| **TeachingPlanAgent** | 基于大纲生成完整教案 | 教学目标、重难点、教学过程 |
| **PPTGenerationAgent** | 根据教案生成课件大纲 | PPT 页面结构与内容 |
| **ExperimentGuideAgent** | 生成实验指导书 | 实验目的、原理、步骤 |
| **QuestionGenerationAgent** | 按知识点和难度出题 | 结构化题目列表（JSON） |
| **TopicGenerationAgent** | 生成课堂讨论话题 | 话题、引导问题、评分标准 |
| **TeachingPlanBaseInfoAgent** | 生成完整教案 | 结构化教案文件 |
| **ExperimentGuideBaseInfoAgent** | 生成完整实验指导书 | 结构化实验指导书 |

### 架构特点

- **独立构建** — 每个 Agent 独立实例化，拥有独立的 SystemPrompt 和 MemorySaver
- **多模型支持** — 底层支持 DashScope（通义千问）、OpenAI 兼容接口（DeepSeek 等）多模型接入
- **上下文记忆** — 基于 MemorySaver + Checkpoint 机制实现多轮对话上下文管理
- **结构化输出** — 通过 `outputType` 实现 JSON 结构化输出，直接映射为业务 DTO
- **流式响应** — 支持 SSE 流式输出，用户可实时查看 AI 生成进度

## 技术架构

### 后端

| 技术 | 说明 |
|------|------|
| **Spring AI Alibaba** | AI 智能体框架，提供 ReactAgent、Graph 工作流、工具调用等能力 |
| **Spring Boot 3.2** | 核心应用框架 |
| **MyBatis** | 持久层框架 |
| **MariaDB** | 主数据库存储 |
| **Redis** | 缓存与会话管理 |
| **RustFS** | 文件存储（课件、图片等资源） |
| **WebSocket + SSE** | 实时通信，支持流式 AI 输出推送 |

### 前端

| 技术 | 说明 |
|------|------|
| **Vue 3 + Vite** | 前端框架与构建工具 |
| **Ant Design Vue** | UI 组件库 |
| **ECharts** | 数据可视化（学情分析热力图、雷达图等） |
| **KaTeX** | 数学公式渲染 |

### 大模型

| 模型 | 接入方式 | 用途 |

## 快速开始

### 环境要求

- JDK 17+
- Node.js 18+
- MariaDB 5.7+
- Redis 6+

### 后端启动

```bash
# 1. 导入数据库
mysql -u root -p < doc/legend_smartmind.sql

# 2. 配置 API Key
# 编辑 legend-smartmind/src/main/resources/application.yml
# 设置 spring.ai.dashscope.api-key 或环境变量

# 3. 编译并启动
cd legend-smartmind
mvn clean package -DskipTests
java -jar target/legend-smartmind-1.0.0.jar
```

### 前端启动

```bash
cd ui-manager
npm install
npm run dev
```

访问 `http://localhost:3000` 即可使用。
